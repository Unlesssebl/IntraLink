# Workflow: Сетевая диагностика (`/diag <ХОСТ/IP>`)

Проверяет доступность корпоративного компьютера или сетевого устройства.

## Шаги выполнения:
1. **Запуск диагностики:** Выполнить команду `uv run python helpdesk_tool.py diagnose <ХОСТ_ИЛИ_IP>` в каталоге `helpdesk_agent/`.
2. **Проверка портов:** Анализирует ICMP Ping, DNS-резолвинг в домене, порт `SMB 445` и `WinRM 5985`.
3. **Вывод статуса:** Если ICMP заблокирован файрволом, но SMB/WinRM открыт — выводит статус хоста как `🟢 В СЕТИ`.

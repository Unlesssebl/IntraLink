# Workflow: Детальный просмотр задачи (`/task <ID>`)

Загружает полную информацию по указанному инциденту, извлекает кастомные поля, историю действий и семантический RAG-контекст.

## Шаги выполнения:
1. **Запрос данных:** Выполнить команду `uv run python helpdesk_tool.py task <ID>` в каталоге `helpdesk_agent/`.
2. **Анализ:**
   - Извлечь контактные данные заявителя, рабочую станцию, кабинет, телефон;
   - Проверить сетевое состояние ПК;
   - Изучить историю переписки и комментариев инженеров (`uv run python helpdesk_tool.py history <ID>`);
   - Найти похожие кейсы в RAG (`uv run python helpdesk_tool.py search-kb "<проблема>"`).
3. **Презентация:** Вывести детальную карточку с обоснованной рекомендацией статуса и готовым проектом ответа по шаблону Беликова Алена.

### Задачи и решения:

1. **Не консистентная реализация кнопок в плане дизайна, эмодзи быть не должно, желательно придерживаться монохромных цветов:**
   - [x] Согласовано: переход на монохромные кнопки (Primary: нейтрал, Secondary: нейтральная рамка, Ghost).
   - [x] Убрать яркие фоновые плашки (amber, indigo) в панели фильтров очереди.
   - [x] Заменить все эмодзи (`⚡`, `📚`, `🟢`/`🟡`/`🔴`, `🛡`, `✕`, `✓`) на векторные SVG-иконки из `Icons.tsx` и статус-доты.

2. **Столбец "решение AI " выделяется по сравнению с другими, нету консистентности в UI:**
   - [x] Согласовано: заголовок столбца в `thead` переводится в стандартный нейтральный `text-neutral-400 dark:text-neutral-500` (без синего цвета).
   - [x] Кнопка целевого действия оформляется как аккуратная монохромная кнопка вторичного типа с SVG-стрелкой перевода и статус-дотом.
   - [x] При статусе «В работе» отображается лаконичный статичный статус-бейдж.

3. **Сделать интерфейс крупнее в целом:**
   - [x] Согласовано: системный подъем размеров шрифтов и отступов.
   - [x] Таблица: строки `h-[66px]` (вместо 58px), заголовки заявок `text-[15px]` (вместо 13.5px), бейджи/кнопки `text-[12.5-13px]`.
   - [x] Инспектор: увеличенные поля ввода (текст ответа, списание минут, заголовки секций).

4. **Сделать одинаковое расстояние между столбцами:**
   - [x] Согласовано: перевод таблицы на `table-fixed` со строгой сеткой ширин:
     - Чекбокс: `w-12` (48px)
     - СТАТУС: `w-40` (160px)
     - РЕШЕНИЕ AI: `w-44` (176px)
     - ЗАЯВКА: `w-auto` (flex-1)
     - СЕРВИС: `w-48` (192px)
     - ХОСТ: `w-36` (144px)
     - ИСПОЛНИТЕЛЬ: `w-40` (160px)
     - SLA: `w-28` (112px)
   - [x] Единый горизонтальный отступ ячеек `px-3.5` для одинаковых визуальных промежутков.

5. **Рефакторинг больших модулей, например ticketinspector:**
   - [x] Согласовано: декомпозиция `TicketInspector.tsx` (1671 строка) на 10 подкомпонентов в каталоге `src/components/inspector/` (`InspectorHeader`, `RequesterCard`, `DiagnosticsSection`, `AiTriageCard`, `AiSummarySection`, `RagMatchesSection`, `WorkerActionsSection`, `AttachmentsSection`, `ReplyActionForm`, `CommentsTimeline`).
   - [x] Разгрузка `QueuePage.tsx` (1440 строк) с выносом модальных окон в `src/components/queue/` (`SmartBatchModal`, `BulkConfirmModal`, `QueueFiltersBar`).

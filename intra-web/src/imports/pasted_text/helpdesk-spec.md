РОЛЬ И КОНТЕКСТ
──────────────
Спроектируй профессиональный веб-интерфейс Helpdesk-центра IntraLink.
Аудитория — инженеры технической поддержки 1–2 линии, которые ежедневно
обрабатывают десятки заявок. Интерфейс должен быть ориентирован на скорость
работы и минимальное число кликов.


СТИЛЕВОЕ НАПРАВЛЕНИЕ
─────────────────────
Ориентир — рабочее пространство Notion: сдержанное, типографически чистое,
без декоративных элементов.

Принципы, которым нужно следовать:
- Монохромная нейтральная основа. Цвет применяется только как смысловой
  маркер (статус, приоритет, SLA), а не для декора.
- Тонкие разделители вместо теней. Границы и отступы строят структуру,
  не рамки с тенями.
- Компактные пастельные теги-пилли для свойств (статус, приоритет, категория).
  Насыщенность невысокая: лёгкий оттенок фона + более тёмный текст того же хроматического ряда.
- Типографика строит иерархию. Жирность, размер и прозрачность текста —
  основные инструменты акцентирования.
- Тёмная и светлая темы с явным переключателем. Семантика цвета (нейтральный,
  акцент, успех, предупреждение, критично, muted) сохраняется в обеих темах.
- Минимальные скругления (4–6px). Интерфейс — рабочий инструмент, не промо-сайт.


СТРУКТУРА МАКЕТА
─────────────────

Глобальная компоновка:
  Двухпанельный shell: коллапсируемый сайдбар слева + основная рабочая область справа.
  При открытой карточке заявки — трёхпанельная раскладка (список + инспектор).

Сайдбар:
  - Название воркспейса и аккаунт оператора.
  - Строка быстрого поиска (Ctrl+K).
  - Навигационные пункты со счетчиками:
      · Очередь заявок
      · Центр автоматизации
      · Настройки
  - Сохранённые фильтры / Избранное (Starred).
  - Статус оператора и переключатель темы — внизу.

Topbar:
  - Breadcrumbs: Воркспейс / раздел / тикет (кликабельные).
  - Контекстные действия текущего экрана.


1. ОЧЕРЕДЬ ЗАЯВОК
──────────────────

Заголовок-тулбар:
  - Переключатель видов: Таблица | Канбан | Список.
  - Панель управления: Filter | Sort | Group по произвольному свойству.
  - Сегментный переключатель AI-потоков: Все | Готов ответ AI | Требуют решения.
  - Глобальный поиск по очереди (ID, тема, ФИО, хост).

Табличный вид (основной):
  - Inline Editing: клик на ячейку статуса или исполнителя — Popover без открытия карточки.
  - Чекбокс выбора строки появляется при наведении.
  - Свойства каждой строки:
      · Заголовок тикета (кликабельный, открывает инспектор).
      · Статус (пастельный пилл с цветом по смыслу).
      · Приоритет (пастельный пилл).
      · AI-сигнал (тег уверенности).
      · Категория услуги.
      · Исполнитель (аватар или кнопка самоназначения).
      · Заявитель.
      · Хост / IP (моноширинный тег).
      · SLA (дедлайн, цвет меняется по мере приближения срока).
  - Виртуализация рендеринга для плавного скролла при больших списках.

Канбан-вид:
  - Колонки по статусам: Новые, В работе, Ожидание, Решено.
  - Drag & Drop между колонками.
  - Компактные карточки: приоритет, SLA, аватар исполнителя.

Плавающая панель пакетных действий:
  - Появляется снизу при выборе хотя бы одной строки.
  - Акцентный тёмный стиль (контрастирует с основным фоном).
  - Действия: Взять себе | Назначить | Сменить статус | Перенаправить | Слить дубликаты.


2. КАРТОЧКА ЗАЯВКИ (ИНСПЕКТОР)
────────────────────────────────

Открывается как боковая панель (Side Peek) без потери контекста списка.
Поддерживает разворот в полноэкранный режим.

Шапка:
  - Заголовок тикета (H1), номер со ссылкой на внешнюю систему.

Сетка свойств (в стиле Notion Properties):
  Кликабельные поля для быстрой правки без отдельного редактора.
  - Статус, Приоритет, Исполнитель, Заявитель, Телефон,
    Хост / IP, SLA, Категория.
  - Кнопка копирования рядом с каждым текстовым значением.

Информационные блоки (Callout):
  - Сетевая диагностика хоста: Ping, SMB/445, WinRM — с кнопкой обновления.
  - Подсказка базы знаний: найденное похожее решение с кнопкой «Вставить в ответ».
  Стиль блоков — нейтральный/предупреждающий callout, без яркости.

Тело страницы:
  - Описание проблемы с поддержкой Markdown и блоков кода.
  - Галерея вложений с открытием в полноэкранном Lightbox.

История (Timeline):
  - Хронологическая лента: статусы, назначение, системные события.
  - Визуальное разделение публичных ответов и внутренних заметок инженера.

Редактор ответа:
  - Переключатель режима: Ответ заявителю / Внутренняя заметка.
  - Поддержка слэш-команд (/) для вставки шаблонов и быстрых действий.
  - Кнопки завершения: Отправить | Отправить и закрыть | Перенаправить.


3. ЦЕНТР АВТОМАТИЗАЦИИ
───────────────────────

Верхняя статистика:
  - Счетчики за текущий день: обработано, готовых ответов AI, найдено дубликатов.
  - Ручные триггеры: запуск триажа, синхронизация базы знаний.

Двухпанельная раскладка:
  Левая — каталог услуг (дерево с прогресс-баром наполненности RAG и чекбоксами включения).
  Правая — детали выбранного раздела:
    · Настройки порога уверенности и лимитов.
    · Библиотека примеров (просмотр, добавление, удаление).
    · Тест-площадка: ввод описания → ответ AI с confidence.

Лента событий агента:
  - Список последних действий с раскрываемыми деталями.

Консоль логов:
  - Тёмный моноширинный терминал с подсветкой уровней (INFO, WARN, ERROR, SUCCESS).
  - Фильтр по уровню, поиск, автоскролл.


4. НАСТРОЙКИ
─────────────

Разделы в виде карточек:
  - Статус сервисов: мониторинг интеграций (API, очередь, БД, бот) с кнопкой обновления.
  - Параметры очереди: источник, движок классификации (только чтение).
  - Интерфейс: тема, плотность таблицы, видимость колонок, звуковые уведомления.


5. ГЛОБАЛЬНЫЕ КОМПОНЕНТЫ
─────────────────────────

Command Palette (Ctrl+K):
  Поиск по разделам и тикетам, запуск общих действий.

Toast Notifications:
  Плавающие уведомления с семантическими состояниями: успех, ошибка,
  предупреждение, фоновый прогресс.

Image Lightbox:
  Полноэкранный просмотр вложений с зумом.

Авторизация:
  Минималистичная форма входа (логин / пароль).


СЕМАНТИКА ЦВЕТОВ
─────────────────
Не задавай конкретные hex-значения. Следуй смысловой системе:

  neutral     — базовый фон, разделители, текст-заглушки.
  accent      — основные интерактивные элементы (кнопки, ссылки).
  success     — выполнено, активно, онлайн.
  warning     — ожидание, приближение SLA, осторожность.
  critical    — нарушение SLA, ошибка, высокий приоритет.
  muted       — вспомогательный текст, метки без акцента.

Property Pills строятся по той же схеме: лёгкий семантический фон +
более тёмный текст того же хроматического ряда (не насыщенный).


КЛАВИАТУРНОЕ УПРАВЛЕНИЕ
────────────────────────
Интерфейс должен быть полностью управляем с клавиатуры:
  - Навигация по списку стрелками.
  - Выбор строк через чекбоксы (Shift + клик для диапазона).
  - Открытие карточки по Enter.
  - Подтверждение действий по Ctrl+Enter.
  - Закрытие инспектора по Esc.
  - Command Palette через Ctrl+K.

# 💻 Helpdesk CLI — AGY AI Agent Toolset

> [!IMPORTANT]
> Данный пакет спроектирован и используется **исключительно как машинный инструментарий (Tooling SDK) для AI-агента Antigravity (AGY)**.
> Пакет не предназначен для прямого использования человеком как терминальный интерфейс. Инженеры взаимодействуют с системой через диалог с AI-ассистентом, Web SPA `/admin` или Telegram-бот.

---

## 🎯 Назначение
- Предоставление низкоуровневых интерфейсов исполнения для слэш-команд AGY:
  - `/triage` — пакетный разбор очереди заявок 1-й линии (`helpdesk.py batch`)
  - `/task <ID>` — детальная карточка инцидента (`helpdesk.py task`)
  - `/diag <HOST>` — сетевая экспресс-диагностика хостов (`helpdesk.py diagnose`)
  - `/screen <ID>` — скачивание вложений для визуального анализа (`helpdesk.py attachment`)
  - `/kb <QUERY>` — семантический RAG-поиск решений (`helpdesk.py search-kb`)
  - `/sync` — синхронизация закрытых заявок в векторную базу знаний (`helpdesk.py sync-kb`)
  - `/redirect` — отмена заявок не из профильного сервиса (`helpdesk.py redirect`)
- Все запросы направляются строго через **Core API Gateway** (`http://127.0.0.1:8000`).

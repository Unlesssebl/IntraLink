# IntraBot-gemini

Телеграм-бот для мониторинга и управления заявками в системе IntraService. Бот уведомляет пользователей о новых заявках и комментариях, а также позволяет просматривать список активных задач.

## 🚀 Основные возможности

*   **Персональная авторизация**: Каждый пользователь авторизуется под своими учетными данными IntraService. Данные сохраняются в локальной БД.
*   **Гибкое меню**: Управление ботом осуществляется через удобные Reply-кнопки (интерфейс меняется в зависимости от статуса авторизации).
*   **Умный мониторинг**:
    *   Уведомления о **всех новых заявках** в системе.
    *   Уведомления о **комментариях и смене статуса** только для тех заявок, где пользователь назначен исполнителем.
    *   Прямые ссылки на заявки в каждом уведомлении.
*   **Просмотр тикетов**: Команда "📋 Мои заявки" с поддержкой пагинации (по 5 штук) и фильтрацией (только активные задачи, где пользователь — исполнитель).
*   **Безопасность**: Автоматическое удаление сообщений с паролями при авторизации.

## 🛠 Технологический стек

*   **Python 3.10+**
*   **aiogram 3.x**: Асинхронный фреймворк для Telegram Bot API.
*   **APScheduler**: Планировщик для надежного фонового мониторинга.
*   **aiohttp**: Асинхронные запросы к IntraService API.
*   **aiosqlite**: Асинхронная база данных SQLite.
*   **python-dotenv**: Управление конфигурацией.

## 📂 Структура проекта

```text
├── database/
│   └── db.py           # Работа с SQLite (Row-factory, миграции)
├── handlers/
│   ├── auth.py         # Авторизация (Login/Logout), удаление паролей
│   ├── start_help.py   # Команды /start, /help и Reply-меню
│   └── tickets.py      # Просмотр заявок с пагинацией и фильтрацией
├── services/
│   ├── api.py          # Клиент IntraService API (обработка дат, мапинг статусов)
│   └── scheduler.py    # Фоновый мониторинг (новые задачи, комментарии)
├── config.py           # Загрузка конфигурации
├── main.py             # Точка входа (инициализация бота и APScheduler)
└── requirements.txt    # Зависимости
```

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_репозитория>
   cd IntraBot-gemini
   ```

2. **Настройте окружение**:
   Создайте файл `.env`:
   ```env
   BOT_TOKEN=ваш_токен_телеграм_бота
   INTRAService_URL=https://ваш-домен.intraservice.ru/api/
   POLLING_INTERVAL=10
   ```

3. **Запустите через venv**:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate  # Windows
   pip install -r requirements.txt
   python main.py
   ```

## 📝 Кнопки меню

*   **🔑 Авторизация** — Вход в IntraService.
*   **📋 Мои заявки** — Список ваших активных задач (с кнопками пагинации).
*   **🚪 Выйти** — Удаление данных авторизации и остановка уведомлений.
*   **❓ Помощь** — Краткая справка.

## ⚠️ Примечание по API

Бот использует IntraService API v4.47. Для корректного отображения статусов используется механизм `include=status` и внутренний мапинг `StatusId -> StatusName`. Даты обрабатываются с точностью до секунд для предотвращения дублирования уведомлений.

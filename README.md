# IntraBot-gemini

Телеграм-бот для мониторинга и управления заявками в системе IntraService. Бот уведомляет пользователей о новых заявках и комментариях, а также позволяет просматривать список активных задач.

## 🚀 Основные возможности

*   **Персональная авторизация**: Каждый пользователь авторизуется под своими учетными данными IntraService. Данные сохраняются в локальной БД.
*   **Гибкое меню**: Управление ботом осуществляется через удобные Reply-кнопки (интерфейс меняется в зависимости от статуса авторизации).
*   **Умный мониторинг**:
    *   Уведомления о **всех новых заявках** в системе.
    *   Уведомления о **комментариях и смене статуса** только для тех заявок, где пользователь назначен исполнителем.
    *   Прямые ссылки на заявки в каждом уведомлении.
*   **Просмотр тикетов**: Команда "📋 Мои заявки" с поддержкой пагинации (по 5 штук) и фильтрацией (только активные задачи, где пользователь — исполнитель).
*   **Безопасность**: Автоматическое удаление сообщений с паролями при авторизации.

## 🛠 Технологический стек

*   **Python 3.10+**
*   **aiogram 3.x**: Асинхронный фреймворк для Telegram Bot API.
*   **APScheduler**: Планировщик для надежного фонового мониторинга.
*   **aiohttp**: Асинхронные запросы к IntraService API.
*   **aiosqlite**: Асинхронная база данных SQLite.
*   **python-dotenv**: Управление конфигурацией.

## 📂 Структура проекта

```text
├── database/
│   └── db.py           # Работа с SQLite (Row-factory, миграции)
├── handlers/

```

## ⚙️ Установка и запуск

### Вариант 1. Запуск через Docker (Рекомендуется для обхода VPN)

Если хост-машина находится под управлением Windows и подключена к VPN, который нарушает маршрутизацию Docker-контейнеров, данный способ позволяет пустить трафик контейнера напрямую с использованием прокси-сервера и альтернативных DNS.

1. **Настройте окружение**:
   Создайте файл `.env` (в корне проекта):
   ```env
   BOT_TOKEN=ваш_токен_телеграм_бота
   INTRAService_URL=https://ваш-домен.intraservice.ru/api/
   POLLING_INTERVAL=10
   DB_PATH=/app/data/intrabot.db

   # Опционально: Настройка прокси-серверов для обхода VPN
   # Используйте host.docker.internal для адресации к локальному хосту Windows из контейнера
   # TELEGRAM_PROXY=http://host.docker.internal:1080
   # INTRAService_PROXY=http://host.docker.internal:1080
   ```

2. **Запустите контейнеры**:
   ```bash
   docker compose up --build -d
   ```

*Примечание:* При запуске через Docker база данных `intrabot.db` сохраняется на хост-машине в каталоге `./data/`. Встроенная в `docker-compose.yml` конфигурация DNS (`8.8.8.8`, `1.1.1.1`) решает проблему с резолвом DNS, часто возникающую при запущенных VPN-клиентах на Windows.

### Вариант 2. Локальный запуск (uv / python)

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url_репозитория>
   cd IntraBot-gemini
   ```

2. **Настройте окружение**:
   Создайте файл `.env`:
   ```env
   BOT_TOKEN=ваш_токен_телеграм_бота
   INTRAService_URL=https://ваш-домен.intraservice.ru/api/
   POLLING_INTERVAL=10
   ```

3. **Запуск с использованием uv**:
   Рекомендуется использовать [uv](https://github.com/astral-sh/uv) для управления зависимостями:
   ```bash
   # Синхронизация зависимостей и создание виртуального окружения (.venv)
   uv sync

   # Запуск бота
   uv run main.py
   ```

4. **Классический запуск через стандартный venv и pip**:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   # source .venv/bin/activate  # macOS/Linux
   pip install -r requirements.txt
   python main.py
   ```

## ⚠️ Примечание по API

Бот использует IntraService API v4.47. Для корректного отображения статусов используется механизм `include=status` и внутренний мапинг `StatusId -> StatusName`. Даты обрабатываются с точностью до секунд для предотвращения дублирования уведомлений.

# 📦 Общий пакет утилит (`shared`)

Единый пакет общих алгоритмов и утилит проекта **IntraLink**, реализующий принцип **Single Source of Truth (SSOT)**.

---

## 📌 Назначение и состав модулей

Пакет предназначен для исключения дублирования фундаментальной логики между микросервисами (`core-api`, `execution-worker`, `helpdesk-cli`):

| Модуль | Назначение | Ключевые функции |
|---|---|---|
| [`normalizer.py`](../../../shared/normalizer.py) | Нормализация и валидация сетевых сущностей | `normalize_pc_name`, `extract_pc_names_from_text`, `is_valid_pc_name`, транслитерация раскладки клавиатуры (RU $\leftrightarrow$ EN) |
| [`diagnostics.py`](../../../shared/diagnostics.py) | Экспресс-диагностика доступности хостов | `run_host_diagnostics`, асинхронный ICMP Ping, DNS lookup, проверка TCP-портов SMB:445 и WinRM:5985 |
| [`json_utils.py`](../../../shared/json_utils.py) | Высокопроизводительная сериализация | `json_dumps`, `json_loads` на базе `orjson` с fallback на `json` |

---

## 🔒 Главный архитектурный инвариант

> [!IMPORTANT]
> **Запрет дублирования логики:**
> Любые копии алгоритмов парсинга хостов, регулярных выражений IP или сетевых зондов в дочерних сервисах **строго запрещены**.
> Дочерние сервисы (`helpdesk-cli`, `execution-worker`) используют модули `shared` напрямую либо через тонкие реэкспорт-стабы. Все доработки ведутся исключительно в каталоге `shared/`.

# 🔐 Аутентификация

Роутер: [auth.py](../../../../core-api/app/routers/auth.py)

Префикс: `/api/v1/auth`

Все эндпоинты требуют передачи заголовка `X-Bot-Api-Key`.

---

## 1. Авторизация и сохранение сессии (`POST /login`)

Используется для проверки учетных данных пользователя во внешнем IntraService и их шифрованного сохранения в локальной базе данных PostgreSQL.

### Запрос

- **Метод:** `POST`
- **Путь:** `/api/v1/auth/login`
- **Тело запроса (JSON):**

| Поле | Тип | Описание |
| :--- | :---: | :--- |
| `tg_user_id` | Integer | ID пользователя в Telegram (используется как первичный ключ сессии). |
| `login` | String | Логин пользователя в IntraService. |
| `password` | String | Пароль пользователя в IntraService (передается в открытом виде для верификации). |

**Пример JSON-запроса:**
```json
{
  "tg_user_id": 123456789,
  "login": "IntraTest",
  "password": "your_password_here"
}
```

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):**

| Поле | Тип | Описание |
| :--- | :---: | :--- |
| `status` | String | Статус операции (обычно `"success"`). |
| `message` | String | Сообщение с результатом выполнения. |
| `is_user_id` | Integer | ID пользователя во внешней системе IntraService. |

**Пример JSON-ответа:**
```json
{
  "status": "success",
  "message": "Авторизация успешно пройдена и сохранена.",
  "is_user_id": 9891
}
```

- **Код ошибки `401 Unauthorized`**: Неверный логин или пароль во внешнем IntraService API.
  ```json
  {
    "detail": "Неверное имя пользователя или пароль в IntraService."
  }
  ```

---

## 2. Выход и удаление сессии (`DELETE /logout`)

Используется для удаления сохраненных учетных данных пользователя из базы данных PostgreSQL. После вызова этого метода фоновый опрос для пользователя прекращается.

### Запрос

- **Метод:** `DELETE`
- **Путь:** `/api/v1/auth/logout`
- **Query-параметры:**

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `tg_user_id` | Integer | Да | ID пользователя в Telegram, сессию которого нужно удалить. |

**Пример запроса:**
`DELETE /api/v1/auth/logout?tg_user_id=123456789`

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):**
  ```json
  {
    "status": "success",
    "message": "Сессия пользователя удалена."
  }
  ```

- **Код ошибки `404 Not Found`**: Если сессия пользователя с указанным Telegram ID не найдена.
  ```json
  {
    "detail": "Пользователь с Telegram ID 123456789 не найден."
  }
  ```

## 1. Проверка работоспособности (`GET /health`)

Используется для мониторинга состояния сервиса. Этот эндпоинт общедоступен и **не требует** передачи авторизационного ключа `X-Bot-Api-Key`.

### Запрос

- **Метод:** `GET`
- **Путь:** `/health`

**Пример запроса:**
`GET /health`

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):**

| Поле | Тип | Описание |
| :--- | :---: | :--- |
| `status` | String | Состояние сервиса (обычно `"healthy"`). |
| `service` | String | Идентификатор сервиса (всегда `"intraservice-core-api"`). |

**Пример JSON-ответа:**
```json
{
  "status": "healthy",
  "service": "intraservice-core-api"
}
```

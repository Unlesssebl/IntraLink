# ⚙️ Сервисные задачи

Роутер: [service_tasks.py](../../../../core-api/app/routers/service_tasks.py)

Все эндпоинты требуют передачи заголовка `X-Bot-Api-Key` для авторизации запроса между сервисами (Service-to-Service).
В отличие от стандартного API [tasks.md](tasks.md), эти эндпоинты **не привязаны к Telegram-пользователям** и выполняют действия во внешнем IntraService от лица **глобального сервисного аккаунта** (например, `IntraTest`).

---

## 1. Получить детали задачи (`GET /api/v1/service/tasks/{task_id}`)

Получает подробную информацию по задаче из IntraService, включая кастомные поля и статус.

### Запрос

- **Метод:** `GET`
- **Путь:** `/api/v1/service/tasks/{task_id}`
- **Параметры пути:**

| Параметр | Тип | Описание |
| :--- | :---: | :--- |
| `task_id` | Integer | Уникальный ID задачи в системе IntraService. |

**Пример запроса:**
`GET /api/v1/service/tasks/12345`

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):** Детали задачи (см. [intraservice_entities.md](intraservice_entities.md)).

- **Код ошибки `502 Bad Gateway`**: Внешний сервис IntraService вернул ошибку при запросе.

## 2. Добавить комментарий к задаче (`POST /api/v1/service/tasks/{task_id}/comment`)

Добавляет комментарий к задаче от лица сервисного аккаунта.

### Запрос

- **Метод:** `POST`
- **Путь:** `/api/v1/service/tasks/{task_id}/comment`
- **Параметры пути:**

| Параметр | Тип | Описание |
| :--- | :---: | :--- |
| `task_id` | Integer | Уникальный ID задачи в системе IntraService. |

- **Тело запроса (JSON):**

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `comment` | String | Да | Текст комментария для добавления. |

**Пример тела запроса (JSON):**
```json
{
  "comment": "🔧 Установка принтера завершена успешно."
}
```

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):**
  ```json
  {
    "status": "success"
  }
  ```

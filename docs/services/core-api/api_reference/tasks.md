# 📋 Задачи и статусы

Роутер: [tasks.py](../../../../core-api/app/routers/tasks.py)

Все эндпоинты требуют передачи заголовка `X-Bot-Api-Key`. 
Для авторизации во внешнем сервисе IntraService под капотом используется сессия пользователя, чей `tg_user_id` передан в качестве query-параметра.

---

## 1. Получить список задач (`GET /api/v1/tasks`)

Запрашивает список задач из внешнего IntraService, проксируя query-параметры фильтрации.

### Запрос

- **Метод:** `GET`
- **Путь:** `/api/v1/tasks`
- **Query-параметры:**

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `tg_user_id` | Integer | Да | ID пользователя в Telegram, чью сессию использовать для запроса к IntraService. |
| Любые фильтры | String / Int | Нет | Дополнительные параметры фильтрации IntraService API (например, `statusId`, `executorId`, `page`, `pageSize` и т.д.). |

**Пример запроса:**
`GET /api/v1/tasks?tg_user_id=123456789&statusId=1&pageSize=10`

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):** Зависит от структуры ответа внешнего API IntraService (см. [intraservice_entities.md](intraservice_entities.md)).

- **Код ошибки `404 Not Found`**: Сессия пользователя с указанным Telegram ID не найдена.
- **Код ошибки `502 Bad Gateway`**: Внешний сервис IntraService вернул ошибку при запросе.

## 2. Получить историю изменений задачи (`GET /api/v1/tasks/{task_id}/lifetime`)

Возвращает журнал жизненного цикла (историю изменений, включая комментарии) конкретной задачи.

### Запрос

- **Метод:** `GET`
- **Путь:** `/api/v1/tasks/{task_id}/lifetime`
- **Параметры пути:**

| Параметр | Тип | Описание |
| :--- | :---: | :--- |
| `task_id` | Integer | Уникальный ID задачи в системе IntraService. |

- **Query-параметры:**

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `tg_user_id` | Integer | Да | ID пользователя в Telegram, чью сессию использовать для запроса к IntraService. |

**Пример запроса:**
`GET /api/v1/tasks/1054/lifetime?tg_user_id=123456789`

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):** Список событий жизненного цикла (см. [intraservice_entities.md](intraservice_entities.md)).

- **Код ошибки `404 Not Found`**: Сессия пользователя с указанным Telegram ID не найдена.
- **Код ошибки `502 Bad Gateway`**: Не удалось получить историю для задачи из внешнего сервиса.

## 3. Получить справочник статусов (`GET /api/v1/statuses`)

Возвращает список всех доступных в системе IntraService статусов для задач.

### Запрос

- **Метод:** `GET`
- **Путь:** `/api/v1/statuses`
- **Query-параметры:**

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `tg_user_id` | Integer | Да | ID пользователя в Telegram, чью сессию использовать для запроса к IntraService. |

**Пример запроса:**
`GET /api/v1/statuses?tg_user_id=123456789`

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):** Список статусов. Каждая сущность содержит ID и название статуса.
  
  **Пример JSON-ответа:**
  ```json
  [
    {
      "Id": 1,
      "Name": "Новая"
    },
    {
      "Id": 2,
      "Name": "В работе"
    },
    {
      "Id": 3,
      "Name": "Закрыта"
    }
  ]
  ```

- **Код ошибки `404 Not Found`**: Сессия пользователя с указанным Telegram ID не найдена.
- **Код ошибки `502 Bad Gateway`**: Не удалось получить справочник статусов из внешнего сервиса.

## 4. Добавить комментарий к задаче (`POST /api/v1/tasks/{task_id}/comment`)

Добавляет новый комментарий к указанной задаче в системе IntraService от лица пользователя.

### Запрос

- **Метод:** `POST`
- **Путь:** `/api/v1/tasks/{task_id}/comment`
- **Параметры пути:**

| Параметр | Тип | Описание |
| :--- | :---: | :--- |
| `task_id` | Integer | Уникальный ID задачи в системе IntraService. |

- **Тело запроса (JSON):**

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| `tg_user_id` | Integer | Да | ID пользователя в Telegram, чью сессию использовать для запроса к IntraService. |
| `comment` | String | Да | Текст комментария для добавления. |

**Пример тела запроса (JSON):**
```json
{
  "tg_user_id": 123456789,
  "comment": "🔧 Запущена автоматическая установка принтера..."
}
```

### Ответ

- **Код состояния:** `200 OK`
- **Тело ответа (JSON):**
  ```json
  {
    "status": "success"
  }
  ```

- **Код ошибки `404 Not Found`**: Сессия пользователя с указанным Telegram ID не найдена.
- **Код ошибки `400 Bad Request`**: Отсутствуют или невалидны обязательные поля запроса.
- **Код ошибки `502 Bad Gateway`**: Не удалось добавить комментарий к задаче во внешнем сервисе.

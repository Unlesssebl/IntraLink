# 📋 Микроплан Milestone 4: API управления и интерфейс администратора (Web UI)

## 🎯 Цель этапа
Разработать и интегрировать элементы управления скрытыми служебными комментариями автопилота в веб-интерфейс администратора (`intra-web`), позволяющие инженерам и администраторам централизованно включать/отключать комментарии, регулировать глубину отчётов (`applied` / `technical`) на глобальном уровне и переопределять их для каждого конкретного сценария.

---

## 🧱 Задачи Milestone 4

### 1. Доработка TypeScript-типов и API клиента (`intra-web/src/lib/ticketRuns.ts`)
* Расширение интерфейса `AutopilotSetting`:
  - `internal_comments_enabled?: boolean;`
  - `internal_comments_depth?: 'applied' | 'technical';`
* Обновление функции `updateAutopilotSetting`:
  - Поддержка передачи `internal_comments_enabled` и `internal_comments_depth` в полезной нагрузке `PUT /api/v2/autopilot`.
* Поддержка ключей переопределения комментариев в `AutopilotScenario.config`:
  - `internal_comments_enabled?: boolean;`
  - `internal_comments_depth?: 'applied' | 'technical';`

### 2. Frontend: Глобальные настройки служебных комментариев (`intra-web/src/pages/SettingsPage.tsx`)
* В карточке **«Автопилот заявок»** добавление компактного блока управления служебными комментариями:
  - **Тумблер активности:** переключатель «Скрытые комментарии автопилота» (`Включено / Выключено`).
  - **Селектор глубины отчёта:** выбор уровня детализации:
    - `Прикладной (1-2 предложения для инженеров 1-й линии)` (`applied`);
    - `Технический (структурированный JSON-дамп)` (`technical`).
  - Информационная подсказка о DLP-защите и видимости только для сотрудников поддержки (`IsPrivateComment = true`).
  - Обработчик сохранения с мгновенным Toast-уведомлением и обновлением локального состояния.

### 3. Frontend: Точечное переопределение для каждого сценария
* В таблице / списке сценариев автопилота (`autopilot.scenarios`):
  - Добавление селектора переопределения режима комментариев для сценария:
    - `Наследовать глобально` (используется глобальный дефолт);
    - `Прикладной отчёт` (`applied`);
    - `Технический trace` (`technical`);
    - `Отключить для сценария` (`disabled`).
  - Сохранение через существующий метод `handleToggleScenario` в `scenario.config`.

### 4. Верификация сборки и тестов интерфейса
* Проверка типов TypeScript через `tsc` / `npm run build` в `intra-web`.
* Проверка взаимодействия с бэкендом (GET/PUT эндпоинты).

---

## 🔍 Критерии приёмки Milestone 4
1. В интерфейсе `SettingsPage.tsx` администратор может переключать глобальный тумблер и глубину комментариев.
2. В списке сценариев доступен каскадный выбор (наследование / прикладной / технический / отключено).
3. Сборка фронтенда проходит без ошибок типов.

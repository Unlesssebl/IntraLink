# Workflow: Поиск по базе знаний (`/kb <запрос>`)

Выполняет семантический векторный поиск решений похожих инцидентов.

## Шаги выполнения:
1. **Поиск:** Выполнить команду `uv run python helpdesk-cli/helpdesk.py search-kb "<ЗАПРОС>"`.
2. **Отображение:** Вывести релевантные исторические заявки с исходными формулировками проблем, проверенными решениями и степенью сходства.

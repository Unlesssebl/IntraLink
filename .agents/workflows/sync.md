# Workflow: Синхронизация базы знаний (`/sync [LIMIT]`)

Выгружает решенные и закрытые инциденты из IntraService, фильтрует качественные решения и индексирует их в PostgreSQL pgvector и локальный кэш.

## Шаги выполнения:
1. **Запуск синхронизации:** Выполнить команду `uv run python helpdesk-cli/helpdesk.py sync-kb --limit <N>` (по умолчанию N=50).
2. **Отчет:** Вывести сводную статистику: сколько заявок выгружено, сколько прошло фильтр качества и проиндексировано в хранилище.

# Workflow: Пакетный триаж заявок (`/triage`)

Выполняет сквозной пакетный анализ входящей очереди заявок 1-й линии (Filter ID: 984) с сетевой диагностикой ПК, семантическим поиском решений в pgvector и интерактивным согласованием действий.

## Шаги выполнения:
1. **Проверка статуса БД:** Выполнить команду `uv run python helpdesk-cli/helpdesk.py check-db`. Если PostgreSQL не запущен, выполнить `start-db`.
2. **Получение стопки заявок:** Выполнить `uv run python helpdesk-cli/helpdesk.py batch --limit 5` (или с заданным лимитом N).
3. **Презентация карточек:** Вывести в чат сводную таблицу заявок со статусами сети и подробные структурированные карточки каждой заявки (заявитель, кастомные поля, статус хоста, RAG-аналог, проект ответа по корпоративным шаблонам).
4. **Интерактивное согласование (Human-in-the-Loop):** Открыть модальное окно `ask_question` с мультивыбором (`is_multi_select: true`) для подтверждения оператором.
5. **Применение решений:** После выбора применить подтвержденные задачи через `uv run python helpdesk-cli/helpdesk.py apply <ID> --status <STATUS> --comment "<ТЕКСТ>"` и автоматически проиндексировать закрытые тикеты в базу знаний.

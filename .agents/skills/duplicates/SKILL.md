# 🗑️ Workflow: Очистка очереди от заявок-дубликатов (`/duplicates`)

Этот навык обучает AI-агента Antigravity (AGY) обнаруживать и безопасно отменять дублирующие заявки в очереди технической поддержки IntraService от лица инженера **Беликова Алена** (тел. `49-87`).

---

## ⚡ Интерактивные триггеры и Слэш-команды

| Слэш-команда | Фразы на естественном языке | Действие агента |
|---|---|---|
| `/duplicates` `[N]`<br>`/dedup` `[N]` | `найди дубликаты`, `почисти дубли`, `проверь дубли заявок`, `дедупликация` | Сканирование очереди 1-й линии на наличие повторных и дублирующих заявок (по умолчанию до 10 дублей) |
| `/duplicates apply` | `отмени все дубли`, `закрой дубликаты` | Автоматическая отмена всех найденных дубликатов со статусом 30 |

---

## 🔍 Критерии определения дубликатов (`DuplicateDetector`):

1. **Точный дубликат (Exact Match / Дабл-клик):**
   Один и тот же заявитель (`CreatorId`), одинаковый текст/тема (сходство $\ge 85\%$), создана с интервалом $< 48$ часов.
2. **Аппаратный дубликат (Same Host / Device):**
   Один и тот же ПК (`pc_name`) и заявитель при схожести проблемы $\ge 60\%$.
3. **Коллективный дубликат (Same Shared Issue):**
   Разные заявители, но одна и та же рабочая станция (`pc_name`) или сетевой ресурс при схожести описания $\ge 85\%$.
4. **Тематический дубликат в разделе каталога:**
   Тот же заявитель и раздел каталога при идентичной теме ($\ge 85\%$).

---

## 📋 Жизненный цикл обработки дубликата

1. **Определение Master-заявки:** Более ранняя по времени создания заявка признается **Master** и остается в работе.
2. **Перевод дубликата в Статус 30 («Отменена»):** Дубликат переводится в статус 30 через статус 27 с исполнителями `8664,10502` (Беликов Ален + Беликов Ален_assitant) и списанием 5 минут.
3. **Корпоративный комментарий:**
   > *«Заявка отменена, т. к. является дубликатом заявки #<MASTER_ID>.*  
   > *Работы ведутся в рамках основной заявки.*  
   > *Если у вас есть дополнения по проблеме, пожалуйста, оставьте комментарий в заявке #<MASTER_ID>.»*

## 🛠 Доступные CLI-команды (`helpdesk.py`)

```bash
# Поиск и вывод карточек дубликатов в очереди:
uv run python helpdesk.py duplicates --limit 10

# Вывод в формате JSON:
uv run python helpdesk.py duplicates --limit 10 --json

# Применение отмены к дубликату:
uv run python helpdesk.py apply <DUP_ID> --status 30 --comment "Заявка отменена, т. к. является дубликатом заявки #<MASTER_ID>. Работы ведутся в рамках основной заявки. Если у вас есть дополнения по проблеме, пожалуйста, оставьте комментарий в заявке #<MASTER_ID>." --expenses 5
```

# Frontend Design & UI/UX Engineering Skill

## 1. Главные постулаты дизайна (Linear / Vercel Standard)
- **Отказ от дешёвых эмодзи в интерфейсе**: Все действия, индикаторы и пиктограммы реализуются исключительно через векторные SVG-иконки с единой толщиной штриха (`stroke-width="1.5"` или `1.3`), согласованными размерами (14x14, 16x16, 20x20) и нейтральными цветами.
- **Индикаторы реального статуса**: Вместо серых кнопок с надписями используются аккуратные статус-индикаторы (pill с цветовой точкой-дотом и понятной типографикой), гармонирующие с фоном таблицы.
- **Адаптивность метаданных**: Никаких пустых ячеек «—» в фиксированных сетках. Карточки данных (инспектор заявок, профиль, диагностика) используют гибкую группировку и responsive auto-fit.
- **Консистентная цветовая палитра**:
  - `Light Mode`: фоны `#f8fafc` / `#f1f5f9` / `#ffffff`, границы `border-neutral-200/80`, текст `text-neutral-900` / `text-neutral-600`.
  - `Dark Mode`: фоны `#090a0f` / `#12151c` / `#181c24`, границы `border-neutral-800/80`, текст `text-neutral-100` / `text-neutral-400`.
- **Типографика**: Чистые шрифты `Inter` для UI и `JetBrains Mono` для ID заявок, хостов, IP-адресов и временных меток.

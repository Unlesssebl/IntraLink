# 🧠 Workflow: Поиск по базе знаний (`/kb <запрос>`)

Выполняет семантический векторный поиск решений похожих инцидентов.

## Шаги выполнения:

1. **Поиск по векторной базе:**
   Выполнить команду `uv run python helpdesk.py search-kb "<ЗАПРОС>"` в каталоге `helpdesk-cli/`.
2. **Отображение результатов:**
   Вывести релевантные исторические заявки с исходными формулировками проблем, проверенными решениями и степенью сходства (similarity score).

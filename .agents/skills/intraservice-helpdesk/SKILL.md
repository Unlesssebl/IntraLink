# 🛠️ IntraService Helpdesk Skill (AGY-Native)

Этот навык обучает AI-агента Antigravity (AGY) автономно и надежно работать с корпоративным сервис-деском IntraService от лица инженера технической поддержки **Беликова Алена** (ООО «АйТи ТЭМПО», тел. `49-87`, АБК-3, каб. 112).

---

## ⚡ Быстрые команды через утилиту `helpdesk_tool.py`

Для выполнения любых операций с IntraService используйте утилиту в папке `helpdesk_agent/`:

```bash
# 1. Посмотреть открытые заявки в очереди (фильтр 984 по умолчанию)
uv run python helpdesk_tool.py queue --limit 10

# 2. Получить детальную карточку заявки с кастомными полями и комментариями
uv run python helpdesk_tool.py task <ID_ЗАЯВКИ>

# 3. Выполнить сетевую диагностику компьютера (ICMP, DNS, порты 445, 5985, 3389)
uv run python helpdesk_tool.py diagnose <ИМЯ_ПК_ИЛИ_IP>

# 4. Сформировать проект решения ИИ (с диагностикой и проверкой каталога)
uv run python helpdesk_tool.py suggest <ID_ЗАЯВКИ>

# 5. Применить одобренное решение в IntraService (после подтверждения оператора!)
uv run python helpdesk_tool.py apply <ID_ЗАЯВКИ> --status <STATUS_ID> --comment "<ТЕКСТ>" [--expenses <МИНУТЫ>]

# 6. Поиск по официальному дереву услуг
uv run python helpdesk_tool.py catalog --search "<ЗАПРОС>"
```

## 📋 Статусы IntraService

- `27` — **В работе** (стандартное взятие задачи в работу)
- `35` — **Требует уточнения** (ПК не в сети, не хватает данных от заявителя)
- `48` — **Ожидание устройства** (аппаратный ремонт, замена диска, доставка системного блока в 112 каб.)
- `30` — **Отменена** (неверный раздел каталога услуг, требуется пересоздание)
- `29` — **Выполнена** (предоставлен Wi-Fi, настройка завершена)
- `31` — **Открыта** (новая неразобранная заявка)

## 🔄 Обязательный регламент обработки заявки (Human-in-the-Loop)

При получении запроса на разбор заявок агент **строго следует регламенту**:

1. **Загрузка данных:** Запустить `helpdesk_tool.py task <ID>` или `helpdesk_tool.py suggest <ID>`.
2. **Диагностика:** Если в заявке фигурирует имя ПК или IP, проверить доступность хоста в сети.
3. **Проект решения:** Вывести пользователю карточку с анализом:
   - Номер, тема, заявитель, текущий раздел.
   - Результат сетевой диагностики (в сети / не в сети / время ответа).
   - Предлагаемый статус и обоснование.
   - Точный проект комментария пользователю.
4. **Запрос подтверждения (Human-in-the-Loop):**
   - **НЕ отправлять** изменения в IntraService автоматически.
   - Спросить пользователя: *«Применить данное решение к заявке #... или внести корректировки?»*
5. **Исполнение:** После согласия пользователя запустить `helpdesk_tool.py apply ...` и отчитаться об успехе.

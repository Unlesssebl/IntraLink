# 🛠️ IntraService Helpdesk Skill (AGY-Native Batch Triage & RAG)

Этот навык обучает AI-агента Antigravity (AGY) автономно, безопасно и с максимальной скоростью вести очередь заявок технической поддержки в IntraService от лица инженера **Беликова Алена** (ООО «АйТи ТЭМПО», тел. `49-87`, АБК-3, каб. 112).

---

## ⚡ Доступные команды (`helpdesk_agent/helpdesk_tool.py`)

```bash
# 1. ПАКЕТНЫЙ РАЗБОР СТОПКИ ЗАЯВОК (Основной режим работы)
uv run python helpdesk_tool.py batch --limit 5

# 2. Детальная карточка конкретной заявки
uv run python helpdesk_tool.py task <ID_ЗАЯВКИ>

# 3. Сетевая диагностика ПК / IP
uv run python helpdesk_tool.py diagnose <ИМЯ_ПК_ИЛИ_IP>

# 4. Просмотр и скачивание вложений (скриншоты ошибок)
uv run python helpdesk_tool.py attachment <ID_ЗАЯВКИ>

# 5. Поиск по RAG-базе исторических решений
uv run python helpdesk_tool.py search-kb "<ТЕКСТ_ПРОБЛЕМЫ>"

# 6. Умная синхронизация выполненных заявок
uv run python helpdesk_tool.py sync-kb --limit 50

# 7. Применение решения (после подтверждения оператора!)
uv run python helpdesk_tool.py apply <ID> --status <STATUS_ID> --comment "<ТЕКСТ>" [--expenses <МИН>]
```

## 📋 Статусы IntraService
- `27` — **В работе** (стандартное принятие задачи)
- `35` — **Требует уточнения** (ПК не в сети, нет ответа заявителя)
- `48` — **Ожидание устройства** (аппаратный ремонт, замена диска, принести системный блок в 112 каб.)
- `30` — **Отменена** (неверный раздел каталога услуг)
- `29` — **Выполнена** (Wi-Fi предоставлен, инцидент закрыт)
- `31` — **Открыта** (первичный статус)

## 🚀 Регламент взаимодействия с оператором (Human-in-the-Loop)

1. **Запрос очереди:** Когда оператор пишет `«Разбери очередь»`, `«Покажи заявки»` или `«Что там нового?»`, агент запускает `helpdesk_tool.py batch --limit 5`.
2. **Сводная матрица:** Агент выводит чистую Markdown-таблицу с номерами 1..N, сетевыми бейджами (`🟢`/`🔴`/`⚪`), индикатором вложений (`📎`) и предложенными действиями.
3. **Обработка быстрых шорткатов оператора:**
   - **`все` / `+` / `ок`** $\rightarrow$ Агент последовательно применяет все рекомендации через `apply`.
   - **`1, 2, 4`** $\rightarrow$ Агент применяет рекомендации только для выбранных номеров.
   - **`детали N`** $\rightarrow$ Агент запускает `task <ID>` и показывает полную историю и переписку.
   - **`скриншот N`** $\rightarrow$ Агент запускает `attachment <ID>`, скачивает файл и просматривает его через `view_file`.
   - **`шаблон <имя> для N`** $\rightarrow$ Агент переключает шаблон (`hardware_repair`, `1c_issue`, `printer_issue`, `wifi_access`, `pc_offline`, `wrong_service`).
4. **Непрерывное автообучение:** Каждое закрытое решение (`status 29/30`) автоматически индексируется в базу знаний RAG.

## 💬 Каталог адаптивных шаблонов (`templates.json`)
* **`hardware_repair` (Статус 48):** *«Приносите системный блок в АБК 3, 112 каб. на установку операционной системы и настройку ПО. По вопросам звоните на номер 49-87.»*
* **`pc_offline` (Статус 35):** *«Не вижу ПК {pc_name} в сети.\n1. Убедитесь в корректности имени ПК;\n2. Перезагрузите компьютер;\n3. Проверьте подключение сетевого кабеля.\nПо вопросам звоните на номер 49-87.»*
* **`1c_issue` (Статус 27):** *«Ваша заявка принята в работу. Выполняется проверка информационной базы и очистка кэша 1С на рабочей станции {pc_name}.\nПо вопросам звоните на номер 49-87.»*
* **`printer_issue` (Статус 27):** *«Ваша заявка принята в работу. Выполняется проверка сетевого порта и очереди печати принтера на рабочей станции {pc_name}.\nПо вопросам звоните на номер 49-87.»*
* **`wifi_access` (Статус 29):** *«Доступ к Wi-Fi предоставлен. Используйте логин и пароль от вашей учетной записи на ПК. Инструкцию приложил. Если возникнут проблемы, приходите в АБК-3, каб. 112.»*
* **`wrong_service` (Статус 30):** *«Заявка отменена, т. к. создана не в подходящем разделе. Требуется оставить заявку в подходящем разделе: {target_service}.»*

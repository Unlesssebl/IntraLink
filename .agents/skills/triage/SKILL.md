# 📋 Workflow: Пакетный триаж заявок (`/triage`)

Выполняет сквозной пакетный анализ входящей очереди заявок 1-й линии (Filter ID: 984) с сетевой диагностикой ПК, семантическим поиском решений в pgvector и интерактивным согласованием действий. Поддерживает разбор как всей очереди, так и фильтрацию по **человеческому номеру сервиса** (`01`..`16`).

## Варианты вызова:
- `/triage` — разбор всей стопки заявок из фильтра 1-й линии (по умолчанию 5 заявок).
- `/triage <номер_сервиса>` (например, `/triage 2`, `/triage 03`, `/triage 6`) — сканирование заявок **только указанного сервиса** со всеми его подсервисами.
- `/triage <номер_сервиса> <лимит>` (например, `/triage 2 10`) — выборка до N заявок по указанному разделу.
- `/triage [номер_сервиса] [лимит] /redirect` (например: `/triage 01 5 /redirect`, `/triage 04 /redirect`, `/triage /redirect`) — специализированный поиск заявок, требующих **отмены (30) и редиректа** в другие сервисы каталога.
- `/services` — просмотр таблицы соответствия человеческих номеров разделов (`01`..`16`).

## Шаги выполнения:

1. **Проверка статуса БД (Tier 1 pgvector):**
   Выполнить команду `uv run python helpdesk_tool.py check-db` в каталоге `helpdesk_agent/`. Если PostgreSQL не запущен, вызвать `start-db`.
2. **Получение стопки заявок:**
   - При указании сервиса: `uv run python helpdesk_tool.py batch --service <НОМЕР_ИЛИ_ИМЯ> --limit <N>`.
   - Без указания сервиса: `uv run python helpdesk_tool.py batch --limit 5` (или с заданным лимитом N).
3. **Презентация карточек (Чистая карточка с выделенной цитатой — Вариант 1):**
   Вывести лаконичные карточки заявок прямо в чат: заголовок с бейджем хоста `[PC: 🟢/🔴]`, контакты с иконками `📍`/`📞`, суть проблемы и отдельный блок цитаты `> 💬` с готовым проектом ответа заявителю.
4. **Текстовые шорткаты (Human-in-the-Loop):**
   Завершить сообщение блоком быстрых команд для оператора (`все` / `1, 2, 4` / `детали N`). **Не вызывать модальный `ask_question`**.
5. **Применение решений:**
   После текстового подтверждения оператором применить согласованные задачи через `uv run python helpdesk_tool.py apply <ID> --status <STATUS> --comment "<ТЕКСТ>"` и автоматически проиндексировать закрытые тикеты в базу знаний.

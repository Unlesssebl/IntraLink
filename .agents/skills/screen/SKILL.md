# 🖼️ Workflow: Анализ вложений и скриншотов (`/screen <ID>`)

Скачивает прикрепленные файлы заявки и анализирует текст ошибок на скриншотах.

## Шаги выполнения:

1. **Скачивание вложений:**
   Выполнить команду `uv run python helpdesk_tool.py attachment <ID>` в каталоге `helpdesk_agent/`.
2. **Визуальный осмотр:**
   Открыть полученный файл изображения через системный инструмент `view_file`.
3. **Анализ инцидента:**
   Распознать текст сообщения об ошибке, определить модуль/базу и предложить точечное решение проблемы.

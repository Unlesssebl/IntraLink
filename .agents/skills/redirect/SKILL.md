# 🔄 Workflow: Поиск и пакетная отмена заявок на редирект (`/redirect` / `/triage ... /redirect`)

Выполняет специализированный поиск и пакетный разбор входящих заявок из очереди 1-й линии (Filter ID: 984), которые были **ошибочно зарегистрированы пользователями не в тех разделах каталога услуг** (например, вопросы по 1С или доступ к сетевым папкам внутри раздела «01. Учетные записи» или «04. Сеть»), формирует проекты обоснованной отмены (Статус 30: **Отменена**) с готовым указанием корректного целевого раздела и согласует действия с оператором.

---

## ⚡ Варианты вызова:

- `/triage <номер_сервиса> <N> /redirect` (например: `/triage 01 5 /redirect`, `/triage 04 10 /redirect`) — поиск до N заявок на редирект **внутри указанного раздела**.
- `/triage <номер_сервиса> /redirect` (например: `/triage 01 /redirect`, `/triage 2 /redirect`) — поиск заявок на редирект в указанном сервисе с дефолтным лимитом 5.
- `/triage /redirect` (или `/triage 5 /redirect`) — поиск заявок на редирект **по всей очереди 1-й линии**.
- `/redirect [номер_сервиса] [N]` (например: `/redirect 01 5`, `/redirect 04`, `/redirect`) — прямой шорткат вызова.
- **Естественный язык:** *«найди заявки на редирект в 01»*, *«какие заявки нужно отменить из-за неверного сервиса»*, *«отмени редиректы 04»*, *«покажи заявки на перенаправление»*.

---

## 🛠 Шаги выполнения агента:

1. **Проверка статуса БД:**
   Выполнить `uv run python helpdesk-cli/helpdesk.py check-db`. При необходимости запустить через `start-db`.

2. **Запуск поиска редиректов в CLI:**
   - Для конкретного раздела: `uv run python helpdesk-cli/helpdesk.py redirect --service <НОМЕР> --limit <N>` (или `batch --service <НОМЕР> --limit <N> --redirect`).
   - Для всей очереди: `uv run python helpdesk-cli/helpdesk.py redirect --limit <N>` (или `batch --limit <N> --redirect`).

3. **Компактная презентация карточек (Human-in-the-Loop):**
   Вывести лаконичные 4-строчные карточки по найденным инцидентам:
   - **Заголовок:** `#### [№]. [#<ID>](https://servicedesk.corporate.loc/Task/View/<ID>) ➔ 🎯 Отменена (30) | 🔄 Редирект в «<Целевой сервис>» | 📊 Уверенность: X/10`
   - **Заявитель:** ФИО (Подразделение / Кабинет, Телефон)
   - **Суть проблемы:** Краткое описание проблемы
   - **Причина редиректа:** Обоснование несоответствия (например: *«Заявка оформлена в «04. Проблемы с сетью», но относится к «06. Вопросы по 1С»»*)
   - **Проект ответа:** Готовый текст ответа по корпоративному шаблону:
     > *«Заявка отменена, т. к. создана не в подходящем разделе.\nТребуется оставить заявку в подходящем разделе: <Целевой сервис>.\nЕсли у вас остались вопросы, пожалуйста, напишите в комментариях к этой заявке.»*

4. **Текстовые шорткаты согласования (Human-in-the-Loop):**
   Завершить сообщение блоком быстрых команд для оператора (`все` / `1, 2, 4` / `детали N`). **Не вызывать модальный `ask_question`**, чтобы карточки всегда оставались видимыми в чате.

5. **Применение изменений (`apply`):**
   После текстового подтверждения оператором применить статус `30`, комментарий с маршрутом и списать 5 минут трудозатрат:
   `uv run python helpdesk-cli/helpdesk.py apply <ID> --status 30 --comment "<ТЕКСТ_ОТВЕТА>" --expenses 5`

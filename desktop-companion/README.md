# IntraLink Desktop Companion

Лёгкий Windows tray-helper для запуска LiteManager, DameWare и RDP из
`intra-web`. Он не хранит секреты и принимает только одноразовые deep links,
выданные Core API.

## Локальная настройка пилота

1. Запустите установленный Companion из меню Пуск.
2. В tray-меню выберите **Настройки**.
3. Укажите URL Core API и пути к `romviewer.exe`, `dwrcc.exe` и `mstsc.exe`.

Настройки хранятся только в профиле Windows пользователя. Если путь к клиенту
не задан, web-панель сохраняет fallback: соответствующая команда копируется в
буфер обмена.

## Безопасность

* Разрешены только три типа клиентов и фиксированные аргументы.
* Хост поступает из одноразового разрешения Core API, а не из shell-строки.
* Arbitrary shell/PowerShell, Redis, AD/WinRM и учётные данные не используются.

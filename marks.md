# Задачи и статус доработок (marks.md)

- [x] **1. Кнопка "статус" изменить на индикатор - реальный статус заявки**
  - Реализован компактный статус-бейдж в едином Card/Button стиле `h-7 rounded-lg` с пульсирующим цветным dot жизненного цикла и меню быстрого переключения статуса.
- [x] **2. Определение имен хостов и проверка доступности устройств**
  - Внедрен комплексный экстрактор хостов `extract_pc_names_from_text` (поиск в `CustomFields`, теме `Name`, описании `Description` и маркерах «ПК: ...», «ноут ...»).
  - Реализована параллельная отказоустойчивая диагностика сети (`_check_host_ping_and_ports`): одновременный ICMP Ping + проверка TCP портов SMB (445) и WinRM (5985) + DNS-суффиксы домена (`.tempo.local`). Если открыт порт 445/5985, устройство гарантированно отмечается как ОНЛАЙН даже при блокировке ICMP брандмауэром Windows Defender.
- [x] **3. Стратегия кэширования и отзывчивость**
  - L1 In-Memory кэш Core API с оперативным TTL (15 сек) для отдачи очереди за <10 мс.
  - Автоматическая инвалидация кэша при действиях оператора (`applyTask`, `bulkApplyTasks`).
  - Фоновый опрос через сервис `poller` с Leader Lock.
- [x] **4. Инспектор заявки должен открываться при нажатии на любое место в строке заявки, кроме кнопок**
  - Снята глобальная блокировка событий со всего тега `<td>` хоста.
  - Изолированы только целевые интерактивные элементы (чекбокс, дропдаун статуса, кнопка AI-плана, ссылка на IntraService, бейдж копирования хоста). Клик по всей остальной строке плавно открывает/закрывает карточку `TicketInspector`.

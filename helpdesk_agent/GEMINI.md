## 2. Инструментарий агента (`helpdesk_agent/helpdesk_tool.py`)

Агент в AGY выполняет I/O операции с IntraService через команды:
- `uv run python helpdesk_tool.py batch --limit 5` — пакетный разбор стопки заявок со сводной матрицей.
- `uv run python helpdesk_tool.py task <ID>` — просмотр полной карточки заявки (кастомные поля, история, RAG-контекст).
- `uv run python helpdesk_tool.py diagnose <ПК_ИЛИ_IP>` — комплексная сетевая диагностика хоста (Ping, DNS, SMB 445).
- `uv run python helpdesk_tool.py search-kb "<ТЕКСТ>"` — семантический поиск по проверенным решениям базы знаний.
- `uv run python helpdesk_tool.py sync-kb --limit 50` — умная синхронизация истории заявок в базу знаний.
- `uv run python helpdesk_tool.py apply <ID> --status <ID> --comment "<ТЕКСТ>" [--expenses <МИНУТЫ>]` — применение решения в IntraService после одобрения оператором.
- `uv run python helpdesk_tool.py attachment <ID>` — скачивание вложений заявки для анализа скриншотов ошибок.
- `uv run python helpdesk_tool.py catalog --search "<ИМЯ>"` — валидация разделов по официальному дереву услуг.

## 3. Регламент работы (Интерактивный Human-in-the-Loop)

> [!IMPORTANT]
> **Любые изменения в боевой IntraService вносятся ТОЛЬКО с явного разрешения оператора через интерактивное модальное окно (`ask_question`) или быстрый шорткат.**

1. **Запрос очереди:** При команде «Разбери очередь» агент вызывает `batch --limit 5`.
2. **Сводная матрица:** Агент выводит таблицу очереди с бейджами сети (`🟢`/`🔴`/`⚪`), признаком вложений (`📎`) и проектом адаптивного шаблона.
3. **Интерактивное модальное окно (`ask_question`):** Агент выводит модальный виджет с чекбоксами для быстрой пометки одобренных заявок.
4. **Быстрые шорткаты:** Поддерживаются текстовые команды (`все`, `1, 2, 4`, `детали N`, `скриншот N`, `шаблон <имя> для N`).
5. **Исполнение и автообучение:** После подтверждения вызывается `apply`, а выполненное решение автоматически индексируется в RAG-базу знаний.

  ```text
  2. Перезагрузите компьютер;
  3. Проверьте подключение сетевого кабеля;
  4. Если кабель подключен, проверьте наличие световой индикации в месте подключения кабеля.
  ```

  ```text
  Приносите ПК в АБК 3, 112 каб.
  ```
